# Community code of conduct

Treat contributors and users respectfully. Provide constructive, evidence-based technical feedback. Harassment, discriminatory abuse, threats, doxxing and disclosure of credentials or private research data are unacceptable.

Use public issues and pull requests for non-sensitive project work. Security reports must follow [SECURITY.md](SECURITY.md); do not post private binaries, credentials or vulnerability details publicly. Maintainers may edit/remove harmful content and restrict participation when necessary, considering the context and impact. Apply these expectations in this repository and associated project discussions.
