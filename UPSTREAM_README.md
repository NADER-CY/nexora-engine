# Source origin record

NEXORA ENGINE was developed and expanded from the REA codebase by morluto. The inherited engine was not independently written from scratch.

The import records upstream package `rea-agents` 6.8.0 and commit `3b242491a430b3807853436bfeb9568d606169ac`. These identify source provenance, not an installation recommendation or a NEXORA ENGINE release.

The original MIT license, copyright and third-party attribution remain in [LICENSE](LICENSE), [NOTICE](NOTICE.md) and [third-party notices](THIRD_PARTY_NOTICES.md). The original upstream README remains available in the repository's Git history; marketing badges, star charts, community promotions and upstream package-install commands are intentionally omitted from this current record.

For current installation, capabilities and limitations use the [NEXORA ENGINE homepage](README.md) and [source guide](docs/installation/from-source.md).
