# NEXORA ENGINE identity assets

Original vector artwork for this fork: an angular N with evidence endpoints, an electric-blue evidence network, and responsive light/dark hero layouts. Graph imagery is illustrative and is not a product screenshot. No external fonts, tracking, scripts or network resources are embedded.

- hero-dark.svg / hero-light.svg: 1280×440 desktop heroes.
- hero-mobile-dark.svg / hero-mobile-light.svg: 640×410 compact heroes.
- mark-dark.svg / mark-light.svg: transparent monogram treatment.
- badge-*.svg: static development/source-install/MIT labels, not CI status.
- social-preview.svg / social-preview.png: 1280×640 social sharing artwork. Upload the PNG in the repository's social-preview settings; committing it does not change that GitHub setting.

SVG uses system-font fallbacks. The social PNG is a raster export of the SVG. Artwork is provided under the repository MIT license without changing upstream copyright notices.
