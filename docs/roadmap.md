# NEXORA ENGINE roadmap

1. Documentation/installability: platform and client guides, reproducible offline examples and command/link checks.
2. Binary/Ghidra: bounded metadata improvements, compiler-produced binary fixtures, independent binary identity checks and real provider verification where installed.
3. Semantic source analysis: incrementally expose existing parser/compiler capabilities; preserve unresolved scope/import/call facts. Start with supported JS/TS tooling, then separately verified Go/Rust/C/C++ tooling.
4. Architecture: a unified provenance-bearing graph and Mermaid export; add routes/components only from parsed evidence with honest uncertainty.

See [milestone evidence](milestones.md) for completed work and remaining checks. Planned capabilities are not availability claims. Automatic release/deployment stays disabled; no package or binary release is part of these milestones.
