# Start here

Choose the path that matches your task. Guides and samples are reused from the earlier documentation work; analysis features proposed in [PR #1](https://github.com/NADER-CY/nexora-engine/pull/1) remain separate from main.

| Goal | Start with |
|---|---|
| One local analysis, no dependency install | [README first run](../README.md#first-run) |
| Understand source, binary or cycle results | [Offline tutorials](tutorials/README.md) |
| Check actual demonstration output | [Recorded runs](demos/README.md) |
| Install on a desktop OS | [Windows](installation/windows.md), [Linux](installation/linux.md), [macOS](installation/macos.md) |
| Build the optional full engine | [From source](installation/from-source.md) |
| Configure a client | [Codex](mcp/codex.md), [Claude](mcp/claude.md), [generic MCP](mcp/generic-client.md) |
| Supply Ghidra | [Ghidra workflow](tutorials/ghidra.md) |
| Understand architecture evidence | [Contracts](architecture/README.md) |
| Review proposed work and limitations | [NEXORA roadmap](nexora-roadmap.md), [verification](github-experience-verification.md) |

## Contributing

Read [CONTRIBUTING.md](../CONTRIBUTING.md), use a focused issue/PR, and include a non-sensitive reproduction with actual output, input identity and coverage limits. See [community expectations](../CODE_OF_CONDUCT.md). Never post credentials or private targets; follow [SECURITY.md](../SECURITY.md) for vulnerabilities. The inherited [upstream roadmap](roadmap.md) is retained as historical upstream context, not a NEXORA release promise.
