# NEXORA ENGINE installation

Start with the complete [source installation guide](installation/from-source.md). No official registry package, prebuilt installer or automatic update is offered by this source distribution.

## Choose your platform

- [Windows 10/11](installation/windows.md): offline CLI requires no compiler; full Windows x64 build requires its native addon first.
- [Linux](installation/linux.md): source-derived full build path, not executed in this Windows verification.
- [macOS](installation/macos.md): source-derived full build path, not executed in this Windows verification.
- [Updating safely](installation/updating.md): preserve local changes and use fast-forward updates deliberately.

## Agent integration

[MCP overview](mcp/README.md) · [Codex](mcp/codex.md) · [Claude](mcp/claude.md) · [Generic clients](mcp/generic-client.md). Configure absolute local Node and branded launcher paths after building. No unpublished package runner is needed.

## Optional analysis providers

[Ghidra setup/export/import](tutorials/ghidra.md) · [Ghidra provider contract](ghidra-provider.md) · [IDA](ida-provider.md) · [Kuna](kuna-provider.md) · [Native Windows controls](../native/windows/README.md).

Providers are bring-your-own and have distinct licenses, host support and authority. Real Ghidra execution and live desktop-client connections remain unverified. [Actual verification](github-experience-verification.md) · [Troubleshooting](troubleshooting.md).
