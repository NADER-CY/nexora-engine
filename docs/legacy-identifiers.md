# Legacy identifier and origin policy

NEXORA ENGINE is the product identity. LICENSE, NOTICE.md and THIRD_PARTY_NOTICES.md preserve original MIT and third-party attribution unchanged. UPSTREAM_README.md, changelog release history and prior verification records are historical records rather than current installation recommendations.

Technical compatibility identifiers remain where changing them could break stored data, integrations or resource ownership: `rea` CLI alias, `scripts/rea.mjs`, `rea.json`, `REA_*` environment variables, bridge/class filenames, native artifact/cache directories, wire/error codes, provider protocol labels and fixture bytes. The branded entrypoint is `scripts/nexora-engine.mjs`; existing entrypoints remain available.

The inherited website tree and its verification/generation scripts are archived upstream material, not the project's published homepage or an enabled deployment. Its historic artwork, URLs and fixture labels are retained as history. No separate website is deployed by this milestone.

Source-level origin fields and legal notices identify upstream authorship. Internal comments, archived translations and performance receipt producers record historical implementation context. The archived installation reference preserves upstream acquisition history; the current installation index links maintained source guides and the inherited acquisition script fails closed. Do not blindly rename package dependencies, internal symbols, serialized values, compatibility paths or copyright notices. Human-facing descriptions, plugin identities and active onboarding use the NEXORA ENGINE identity. See [NOTICE](../NOTICE.md).
