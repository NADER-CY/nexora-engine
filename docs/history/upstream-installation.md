# Historical installation provenance

The inherited source originated in the REA project by morluto, package `rea-agents` 6.8.0. Registry installation and package-runner commands from that project are not NEXORA ENGINE installation instructions. Old recipes remain available in Git history rather than being repeated here.

This source distribution is npm-private, disables registry self-update and uses a locally built CLI/MCP launcher. Do not extract a native artifact from an unrelated registry package or substitute that package for this checkout.

Use the [maintained installation guide](../installation/from-source.md), [MCP setup](../mcp/README.md) and [current limitations](../../README.md#security-and-limitations).
