# Reproducible NEXORA ENGINE examples

See [the tutorials](../../docs/tutorials/README.md). Source projects contain no credentials, network activity or production data. `ghidra.synthetic.jsonl` is explicitly synthetic importer input, not a real decompiler result. Compile `sample.c` locally for a real metadata test; generated binaries must stay outside Git. The documentation smoke test executes the offline CLI and checks these examples' expected invariants.
